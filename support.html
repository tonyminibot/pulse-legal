Pulse — Support

Pulse shows your Paddle revenue (today, 7 days, 30 days), transactions and KPIs — combined across multiple accounts, all on-device.

Getting started

In the Paddle dashboard go to Developer Tools → Authentication → API keys → New key. Make it read-only with these permissions: metrics.read, transaction.read, product.read, customer.read, address.read. Paste it into Pulse → Settings → Add account.

FAQ

Is my key safe? Yes — it stays in your device Keychain and only talks to Paddle directly.

Why is the first sync slow? It downloads 60 days of transactions once, then refreshes incrementally. It resumes if interrupted.

Multiple accounts? Add as many keys as you like in Settings; all data is combined.
