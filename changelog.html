Pulse — Changelog

Every shipped version of the iOS app + the source bundle on Polar. Newest first.

v1.0.2 In review submitted 2026-05-22

  • App and App Store listing now in 15 languages — English, Vietnamese, Chinese (Simplified + Traditional), Japanese, Korean, Spanish (Spain + Mexico), Portuguese (Brazil), French, German, Italian, Russian, Arabic (with RTL), Indonesian.
  • In-app Language picker in Settings; auto-detect device language on first launch.
  • Widget marketing-preview now shows a populated demo summary even in unsigned simulator builds.
  • Internal stability improvements.

v1.0 Shipped 2026-05-19

  • Initial App Store release of the native SwiftUI rewrite.
  • Multi-account Paddle dashboard — combined Today / 7-day / 30-day revenue with comparisons against the previous period.
  • Searchable transactions list with on-device cache (62 days), refreshed incrementally.
  • Home Screen + Lock Screen widgets showing all three timeframes.
  • Read-only API key stored in iPhone Keychain. No app account, no server in the data path.
  • App Review demo key + DemoPaddleClient so reviewers can verify the BYOK flow without a real Paddle key (Guideline 2.1(a) compliant).
  • Source bundle launched in parallel — $19 on Polar (full Xcode project, xcodegen, SwiftUI source + AGENTS.md).

Aside (private on-device AI chat) and Skyline (boarding-pass scanner + 3D flight log) are the other apps in Tony's portfolio. All three are built on the same on-device-first philosophy.
